# Software Engineer to Architect Roadmap (C#, .NET, React, Next.js)

English | **[فارسی](README.md)**

A free, step-by-step learning path to become a professional **software engineer**, a **software architect** and a **.NET developer**: from writing your first C# program with zero knowledge to designing distributed systems. The roadmap is an interactive page that saves your progress as you tick off skills.

> **Stack:** C# and .NET on the backend, React and Next.js on the frontend
> **The roadmap itself is written in English.**

## Who is this software architect roadmap for?

- Anyone starting **from zero** who wants to become a **professional software engineer**.
- Developers who want to grow into a **software architect** and are not sure what they are missing.
- Anyone looking for an ordered **.NET roadmap**, from C# and ASP.NET Core to Docker, cloud and microservices.

The design goal is that you can move from phase to phase without a mentor. It is a goal, not a guarantee: if you get stuck, the "Needs" lines tell you which earlier skill to go back to.

## Features

- **11 phases (0 to 10) and 195 skills**, in learning order.
- **A mastery check for every skill:** each skill has one sentence like "I can do X". You tick it when you can do it, not when you have read about it.
- **Priorities:** every skill is tagged **Core** (the spine of the path), **Important** (learn after the core) or **Bonus** (extra depth), and you can filter by priority.
- **Prerequisites ("Needs"):** skills that depend on others say what you should already know.
- **"Ready for the next phase if"** at the end of each phase: a few sentences that tell you when to move on.
- **One flagship project:** you pick one real idea and extend that same project in every phase, so you finish with one coherent portfolio piece.
- **Free, clickable resources** for every section, with one "Start here" link.
- **Progress saved in your browser** (localStorage), plus a light and dark theme.
- **No time estimates:** deliberately, because it depends on how much time you have.

## The .NET roadmap

The .NET path in this roadmap covers: C#, OOP, LINQ and async/await; ASP.NET Core (minimal APIs, DI, middleware); Entity Framework Core and SQL; REST API design; JWT and OAuth; SignalR and gRPC; testing with xUnit and Testcontainers; Docker and CI/CD; and finally messaging, Polly and microservice patterns in the .NET ecosystem.

## The software architect roadmap

The architecture part covers: quality attributes and quality scenarios (ISO 25010), stakeholders and concerns, UML, domain modeling, Clean and Hexagonal architecture, DDD, CQRS and event sourcing, C4 and ADRs, architecture styles, the Strangler Fig pattern and modernization, distributed systems, resilience, architecture evaluation (ATAM and fitness functions), build vs buy, and the communication skills an architect needs.

Its coverage was compared with standards and curricula such as SWEBOK v4, the iSAQB CPSA-F curriculum, SE2014 and ISO/IEC 25010. That comparison is the author's own assessment, not an official certification.

## How to use it

1. Open [Software Architect Roadmap](https://javdanfar.github.io/Software-Architect-Roadmap/ "Open the live roadmap") in your browser.
2. Start at phase 0 and go in order.
3. Tick a skill only when you can do the sentence in its mastery check.
4. If the roadmap feels too big, use the **Core only** filter.
5. Pick one flagship project and extend it in every phase.

Your progress is stored only in that browser on that device. Clearing site data or using a private window removes it.

## FAQ

**Where do I start?** At phase 0. If you already program, skim phases 0 and 1 and tick every skill whose mastery check you can already pass.

**How long does it take?** There is deliberately no time estimate. It depends on the time you put in and on your background.

**Do I need to know every skill?** No. Do Core first, then Important, and Bonus only if you have time.

**Do I need the frontend?** For becoming an architect, yes, at a conceptual level. If you only want the backend, you can do phase 4 after the other phases.
